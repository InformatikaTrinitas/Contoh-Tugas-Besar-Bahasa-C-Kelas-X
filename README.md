## 📌 Deskripsi Program
Program ini merupakan aplikasi kasir sederhana yang dibuat menggunakan bahasa C.  
Aplikasi ini digunakan untuk menghitung total pembelian berdasarkan harga dan jumlah barang, serta memberikan diskon jika memenuhi syarat tertentu.

---

## 🎯 Tujuan
- Memahami dasar pemrograman bahasa C
- Mengimplementasikan konsep:
  - Tipe data
  - Variabel
  - Operator
  - Percabangan
  - Perulangan
  - Fungsi / Prosedur

---

## ⚙️ Fitur Program
- Input jumlah barang
- Input harga dan jumlah setiap barang
- Menghitung total harga
- Memberikan diskon (10% jika total > 100000)
- Menampilkan total pembayaran

---

## 🧠 Konsep yang Digunakan
| Konsep            | Implementasi                    |
|------------------|-------------------------------|
| Tipe Data        | int, float                    |
| Variabel         | harga, jumlah, total          |
| Operator         | +, -, *                       |
| Percabangan      | if-else                       |
| Perulangan       | for                           |
| Fungsi           | hitungTotal(), hitungDiskon() |
| Prosedur         | tampilkanHasil()              |
